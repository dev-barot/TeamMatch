# M9 — Outside users & evidence (the 10 vs 9 ceiling)
**Goal:** real people outside team, friends, and relatives use it; you can prove it. **Owner:** all. **Depends on:** M0, M7.

## What counts
Live URL + one of: analytics, feedback log, user list. Strangers only — other batches, other courses, hackathon/club communities.

## Steps
1. [ ] Freeze a **MVP at week ~8** so people can sign up (verified email, apply, message, matches all work).
2. [ ] Pick a niche where the pain is real: students looking for teammates for **this very semester project** (other sections/batches), hackathon teams, club projects.
3. [ ] Channels: course WhatsApp/Discord groups you're not in, club leads, hackathon organisers, LinkedIn posts, college notice board QR.
4. [ ] Target: ≥ 30 outside signups, ≥ 10 outside Projects or Applications. Track weekly in `docs/EVIDENCE.md`.
5. [ ] Feedback: in-app link to a short form; log every response (date, source, quote, action taken).
6. [ ] Analytics: signups per week, Applications created, Accepted count. Export screenshots/CSV with dates into `docs/evidence/`.
7. [ ] Exclude team, friends, relatives: tag them in a list `docs/evidence/internal-accounts.md` (names only as you're comfortable), filter them out of the numbers.
8. [ ] Fix top 3 feedback items each week; note it in the log, it shows real iteration.
9. [ ] Don't lose the seed illusion: label seed Projects "Demo" so outsiders aren't confused.
10. [ ] Before final: refresh the numbers and link `docs/EVIDENCE.md` from README.

## Done when
README links to the live URL and to an evidence file with dated, outside-user data.
